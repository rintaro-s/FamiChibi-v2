CONCEPT

連絡アプリ、じゃなくて。
家族のリビングを、スマホの中に。

窓の外の空は本物の時間。家にいる人はリビングに、寝ている人はソファでうとうと、出かけている人は「おでかけボード」に。
ちびっこたちは勝手に歩いたり、座ったり、おしゃべりしたりして過ごしています。

4 SCENES

ある家族の、1日。

どの場面も、相手が何も操作しなくても伝わるように作りました。

17:05　放課後
子どもの帰宅見守り

「ただいま」を、打たなくても届ける。

仕事中の母のスマホ。画面の端から娘のちびっこがトコトコ歩いてきて「ただいま！」。
アプリのリビングでは玄関のドアが開き、家族みんなが手を振ってお出迎え。

📶
娘は何も操作していません。
スマホが家のWi-Fi（家族サーバー）につながったことを「帰宅」として検知。吹き出しの「おかえり！」をタップすれば返事になります。
実機のリビング画面（ドアが開く→ただいま）
9:00　離れて暮らす祖母
カメラを使わない見守り

毎朝の「元気？」が、家族みんなに届く。

見守りをONにした祖母のスマホに、毎朝ちびAIが「おはよう！今日も元気？」。大きなボタンで返事をすると、その一言がそのまま家族へ。

🌼
「ちょっと調子わるい」なら急ぎのお知らせに。返事がない・日中4時間スマホに触れていない・電池が15%を切った——そんな時だけ、家族にそっと知らせます。見守りは本人にも表示され、こっそり監視はしません。

18:10　雨の夕方
見逃せない連絡

見逃せない連絡は、見逃させない。

「駅まで迎えに来て！」をちびっこが急ぎと判断。スマホの窓をコンコンとノックし、画面が消えていてもロック画面の上で待っています。

21:30　一人暮らしの兄
遠くても、同じリビングに

ちょうどいい、おせっかい。

📷
カメラも位置情報も使わない共有するのは「家にいる/寝ている/使っている」だけ。共有は自分でOFFにもできます。
👀

🌙
おやすみ時間はそっと急ぎ以外は静かに届け、急ぎだけは起こしてでも届けます。
📇
NFCカードで入力ゼロ参加名前入りのカードをかざすだけで、おばあちゃんも家族サーバーへ。
🏡
家族のデータは家に家族サーバーはPCやラズパイで自分たちで動かせます。
FEEDBACK

予選でいただいたコメントに、
こう応えました。

Qユースケースの考えが不足しています
「子どもの帰宅」「祖父母の見守り」「見逃せない連絡」「一人暮らしの家族」の4つの場面を中心に設計し直しました。どれも相手が何も操作しなくても伝わることを大切にしています。
Q通知を見逃した人への対応（ロック画面への常時表示など）
ロック画面の上にちびっこが現れ、解除せずに返信できます。さらに「窓をノック → 1分後に再ノック → 2.5分後にAIが家族全員へ呼びかけ」と段階的に知らせ、既読になると送り主へ「見たよ！」を報告します。
Q表情や動きがメッセージに合わせて変わると面白い
10種類の感情と緊急度を読みとり、25種類のモーション・7つの表情・パーティクルから届け方を自動で選びます。「なぜこの届け方？」も表示できます。
Q複数のちびっこが表示されても文字が見やすいUIを
吹き出しは重ならないように自動配置。複数あるときは「急ぎ → タップしたもの → 最新」の1つだけを全文表示し、残りは1行のチップにたたみます。文字サイズ設定と、おじいちゃん・おばあちゃんモードもあります。
QAIの判断方法や妥当性・信頼性を説明してほしい
すべてのAIの返事に「なぜ？」（使った道具・参照した会話・判断のきっかけ）を表示。家電や予定などの操作は決定的なルールで処理し、LLMは自由会話だけを担当します。本人の気持ちや予定は推測せず、本人に聞きます。
Q他のSNSとの使い分けが負担にならないか
Androidの共有メニュー「ちびっこに届けてもらう」で、どのアプリからでもそのまま送れます。通知やちびっこの吹き出しからもワンタップで返信できます。
Q機能の盛り込みすぎ・実装面の課題
「家族の気配」という1つのコンセプトに機能を束ね直しました。IoTやAIは家族ごとにON/OFFでき、LLMがなくても動きます。常駐時はアバターのテクスチャを自動で軽量化し、実機（Android 16）で動作を確認しています。
HOW IT WORKS

しくみ

スマホが全部を背負わないように、AIや家電の操作は家族サーバー側へ。

📱 Android

  • 常駐ちびっこ（オーバーレイ）
  • ロック画面ちびっこ
  • けはい（在宅・睡眠・移動）
  • チャット・メモ・予定・通話
  • NFC参加・共有メニュー・TTS

🏡 家族サーバー（Python）

  • FastAPI + SQLite（全文検索）
  • WebSocketでリアルタイム配信
  • 感情・緊急度の読みとり、届け方の判断
  • 見守り・見逃し対策・誕生日のスケジューラ
  • AIちびっこ（ルール＋LLM）

🔌 つながる先

  • Ollama（Qwen など）
  • MCP：仮想の家 / Home Assistant
  • WebRTC 音声通話
