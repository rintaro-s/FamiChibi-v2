サーバーの建て方

家族のメッセージや予定は、自分たちで動かす「家族サーバー」に保存します。Python 3.11以上が入ったPC・Raspberry Pi・VPSならどれでも動きます。

🐍 Python 3.11+⌨ コマンド1つ🔒 データは家族の手元に
1

ダウンロードして起動

サーバー用のフォルダで run.sh を実行するだけです。初回は必要なライブラリを自動でインストールします。

# 作品フォルダの server/ に移動して
cd famichibi/server
./run.sh --port 8010 --name "わが家のサーバー"

Windowsの場合は python -m venv .venv → .venv\Scripts\pip install -r requirements.txt → .venv\Scripts\python -m app.main --port 8010。

💡 同じWi-Fiのスマホは、アプリを開くだけでこのサーバーを自動で見つけます（UDP 47810番でお知らせ）。
2

ずっと動かしておく（ラズパイ・VPS）

電源を入れたら自動で起動するよう、systemdに登録します（Linux）。

# /etc/systemd/system/famichibi.service
[Service]
WorkingDirectory=/home/pi/famichibi/server
Environment=FAMICHIBI_DATA=/home/pi/famichibi/data
Environment=FAMICHIBI_PUBLIC_URLS=http://（外から見たアドレス）:8010
ExecStart=/home/pi/famichibi/server/.venv/bin/python -m app.main --port 8010
Restart=always
[Install]
WantedBy=multi-user.target
sudo systemctl enable --now famichibi

VPSなら付属の tools/deploy_vps.sh ユーザー@アドレス で、コピー・インストール・自動起動までまとめて行えます。

3

家の外からも使う（ポート開放）

  • VPS：ファイアウォールでTCP 8010番を開けます（例：sudo ufw allow 8010/tcp）。
  • 家のPC・ラズパイ：ルーターでTCP 8010番をサーバーへ転送します。転送できない回線では、VPSにサーバーを置くのがおすすめです。
  • FAMICHIBI_PUBLIC_URLS に外から見たアドレスを書いておくと、アプリが家のWi-Fi ⇄ 外でつなぎ先を自動で切り替えます。
⚠ 学校や会社のWi-Fiでは、8010番などの番号への通信が止められていることがあります。その場合はモバイル回線か家のWi-Fiでお試しください。
4

AI・家電はあとから（任意）

  • AIちびっこ：LLMがなくてもルールエンジンで動きます。雑談も楽しみたい場合は Ollama を入れて ollama pull qwen3.5:9b。アプリの「家族」タブ → AIちびっこ設定でURLとモデルを指定します。
  • 家電（Home Assistant）：同じ設定画面の「MCPサーバー」に ha-mcp のURLを追加します。最初は家電が入った仮想の家で試せます。
