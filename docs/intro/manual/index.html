使い方マニュアル

FamiChibiは「家族サーバー」と「アプリ」の2つでできています。サーバーを1台立てて、家族のスマホからつなぐだけ。

⏱ はじめるまで 約5分📱 Android 10以上🖥 PC・ラズパイ・VPS
🖥 サーバーを立てる→📱 アプリでつなぐ→🧸 アバターを選ぶ→🏠 家族のリビングへ
🖥

1. サーバーの建て方

PC・ラズパイ・VPSでコマンド1つ。外から使うときのポート開放も。

読む → 📱

2. アプリをつなぐ

サーバーは自動で見つかります。招待コードかNFCカードで家族に参加。

読む → 🧸

3. アバター(VRM)

3Dで選ぶ・自分のVRMを使う・つかんで投げる。

読む → 🏠

4. 毎日の使い方

ちびっこが届ける連絡、けはい、見守り、AI、サイレント。

読む →

FamiChibiの3つのポイント

  1. 連絡は、送った本人の“ちびっこ”が歩いて届ける — 吹き出し・表情・声で、誰からの連絡かひと目でわかる。急ぎは見逃させない。
  2. 家族の「けはい」が見えるリビング — 帰宅・外出・睡眠を、本人の操作なしで。カメラも位置情報も使わない見守り。
  3. AIは「なぜ？」を話す — 家電操作・予定確認・代わりに聞く。判断根拠をいつでも表示。
