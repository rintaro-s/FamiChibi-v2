# FamiChibi — 家族がいつでもそこにいる。

パソコン甲子園2026 モバイル部門（テーマ「スマホ家族」）／ 鳥羽商船高等専門学校 Team Daijobu

**連絡を送るアプリではなく、「家族の気配」が見えるリビングをスマホに置くアプリです。**
アプリを開くと、家族の“ちびっこ”（VRMアバター）が暮らす小さなリビングがあります。
家にいる人はそこで過ごし、寝ている人はソファでうとうと、出かけている人は「おでかけボード」に。
誰かが帰ってくると玄関のドアが開いて「ただいま！」——**誰も何も送っていなくても**、家族の今が伝わります。

## 4つの場面

### 17:05　放課後 ——「ただいま」を、打たなくても届ける
仕事中の母のスマホ。画面の端から娘のちびっこがトコトコ歩いてきて「ただいま！」。
娘は何も操作していません。スマホが**家のWi-Fi（家族サーバー）につながったこと**を帰宅として検知し、家族全員のリビングでドアが開きます。
吹き出しの「おかえり！」をタップすれば、それが返事になります。

### 9:00　離れて暮らす祖母 —— カメラを使わない見守り
見守りをONにした祖母のスマホに、毎朝ちびAIが「おはよう！今日も元気？」。
大きなボタンで「元気だよ！」と返すと、その一言がそのまま家族に届きます。「ちょっと調子わるい」なら急ぎのお知らせに。
返事がない・日中4時間スマホに触れていない・電池が15%を切った——そんなときだけ、家族にそっと知らせます。
**カメラも位置情報も使いません**。見守りは本人にも表示され、こっそり監視はしません。

### 雨の夕方 —— 見逃せない連絡は、見逃させない
「駅まで迎えに来て！」は急ぎと判断。窓をノックするちびっこ、ロック画面の上のちびっこ、1分未読で再ノック、2.5分誰も見なければAIが家族全員に呼びかけ。
既読になると、送り主のスマホに「見たよ！」とちびっこが報告に来ます。外出中の家族は、リビングの玄関から顔を出して伝えます。

### 夜　一人暮らしの兄 —— 遠くても、同じリビングにいる
アプリを開けば、夜空の見えるリビングで母がソファでうたた寝、父は「おでかけボード」に「3時間前から」。
AIに「電気消して」と頼むと、実家の照明が消えて（MCP経由）、リビングの部屋も本当に暗くなります。
誕生日の0時には、外出中の家族も含めて全員のちびっこが集まってお祝いします。

## 起動方法

### 1. ホストサーバー（PC / Raspberry Pi / VPS）
```sh
cd server
./run.sh --port 8000 --name "わが家のサーバー"
# → http://<LANのIP>:8000  (Webクライアント)   同じWi-FiのスマホからLAN検索で見つかります
```
テスト: `.venv/bin/python -m pytest -q tests`

### 2. AI（任意）
Ollama を起動してモデルを入れ、アプリの「家族」タブ → AIちびっこ設定で URL / モデルを指定します。
```sh
ollama pull qwen3.5:9b            # 企画書どおり。軽くするなら qwen3:1.7b など
OLLAMA_HOST=0.0.0.0 ollama serve  # 別PCで動かす場合は 0.0.0.0 で待ち受け＆11434番を開放
```
**LLMが無くても動きます。** 家電操作・予定確認・代わりに質問・リマインド・過去検索は決定的なルールエンジンが処理し、LLMは雑談など自由会話だけを担当します（ハイブリッド）。

### 3. Android
```sh
cd android
./gradlew :app:assembleRelease     # app/build/outputs/apk/release/app-release.apk (約28MB)
```
初回起動 → LAN検索 or URL入力 → 名前とアバター（3Dプレビュー）→ 家族サーバー作成/参加 → 権限（他アプリの上に表示・通知・マイク）。
「🎬 デモ家族で試す」を押すと、ママ・妹・パパ（仮想メンバー）入りの家族がすぐできます。

### 4. Home Assistant につなぐ
家族タブ → MCPサーバー(JSON) に追加：
```json
[{"name":"home","type":"builtin"},
 {"name":"ha","type":"http","url":"http://homeassistant.local:8086/mcp"}]
```
`type` は `builtin`（デモ家）/`http`（Streamable HTTP）/`stdio`（`command`,`args`,`env`）。デモ家は `python -m app.home` で単体のMCPサーバーとしても動きます。

## 企画書の機能 ↔ 実装

| 企画書 | 実装 |
|---|---|
| 家族の存在感そのものをスマホに（コンセプト） | **けはい（presence）**：在宅/外出（家のWi-Fi到達性）・スマホ使用中/移動中/睡眠を粗く共有し、リビングの部屋・ソファ・玄関・おでかけボードで表現。位置情報・内容は送らない |
| ちびっこが画面の隅からトコトコ来て吹き出しで伝える | 常駐オーバーレイ。画面端から歩いて登場 → 振り向いて表情＋モーション＋吹き出し＋読み上げ（家族ごとに声の高さが違う） |
| 母ちびっこが踊りながら通知（冷蔵庫メモ） | 「15日16時：カレー…」の日時を自動抽出 → その時刻に作者のちびっこが踊って通知 |
| うざったいなら掴んで画面外に投げる | ドラッグで持ち上げ（手足ぶらぶら・髪が揺れる）→ 物理演算で投げる/跳ねる/着地でふらふら。画面外に投げると、次の連絡で端から「のぞき込んで」ぷんぷんしながら戻る |
| 誕生日に家族全員のちびっこが集合 | 誕生日0時 or お祝いメッセージで全員集合＋紙吹雪。「寄せ書き」を事前予約できる |
| 電気を消して（Home Assistant / MCP） | AIがMCP経由で状態確認→必要なときだけ消灯→報告。デモ家（仮想家電）とアプリの「おうち」タブが連動 |
| NFCで簡単参加 | 名前入りの招待をNFCカードに書き込み → かざすだけでアカウント作成〜参加まで入力ゼロ |
| 予定確認・鍵付きカレンダーの人には聞きに行く | 公開カレンダーを集計し、非公開の人には本人に質問を届け、回答が揃ったら集計して報告 |
| RAGで過去のチャット参照 | SQLite FTS5(trigram) 全文検索。回答に引用元（誰がいつ）を表示 |
| ボイスチャット / TTS / 定型文 | WebRTC（Android⇔Web相互）。通話中は参加者のちびっこが音量に合わせて口パク。定型文はバブル・通知・チャットからワンタップ |
| VRM・普段使いのアバター | VRM0/1両対応。自分のVRMをアップロード可。ライセンス情報（クレジット）表示 |

## 予選審査コメントへの回答

| コメント | 対応 |
|---|---|
| 通知を見逃した人への対応（ロック画面への常時表示など） | **ロック画面ちびっこ**：急ぎの連絡・AIからの質問はロック画面の上にちびっこが現れ、解除せずに返信できる。未読があれば画面ONのたびに待っている。**段階的な見逃し対策**：急ぎの連絡が60秒未読→ちびっこが画面を“コンコン”ノック、2.5分誰も見ない→AIが家族全員に「まだ誰も見てないみたい」と呼びかけ。既読になると送り主のちびっこが「見たよ！」と報告 |
| 表情や動きをメッセージ内容に合わせて | 感情（10種）・緊急度を解析して表情・モーション（20種以上）・パーティクルを自動選択 |
| 複数のちびっこが出ても文字が見やすいUI | 吹き出しは重ならないよう自動配置。複数あるときは「急ぎ→タップしたもの→最新」の1つだけ全文表示、他は1行チップに畳む。文字サイズ設定・高齢者モード |
| AIの判断方法・妥当性・信頼性 | すべてのAI応答・届け方に「なぜ？」を表示（使ったツール、参照したチャット、判断キーワード）。家電・予定などは決定的ルールで処理し、LLMは自由会話のみ。本人の気持ち・予定は推測せず本人に聞く |
| 複数アプリの使い分けが負担 | Android共有メニュー「ちびっこに届けてもらう」で他アプリから直接送れる。通知からの直接返信、吹き出しからのワンタップ返信 |
| 機能の盛り込みすぎ・実用性 | IoT・AIは家族サーバー単位でON/OFF。LLMなしでも全主要機能が動く。常駐ちびっこは届けた後に帰る設定も可。VRMテクスチャを自動縮小し常駐時のメモリを抑制 |
| ユースケースの考えが不足 | 「帰宅の見守り（子ども）」「カメラを使わない見守り（祖父母）」「一人暮らしの家族」「見逃せない連絡」の4場面を中心に設計。どれも**相手が何も操作しなくても**伝わる |
| 家族向けとしての特徴・価値 | 「誰から来たか」が一目でわかる存在感、家族ごとの声、つんつん・なでなで、やること完了の報告など“ちょうどよいおせっかい” |

## プレゼンでのデモ手順
1. サーバー起動 → スマホでデモ家族を作成（または NFC カードをかざして参加）
2. スマホをホーム画面に戻す（右下にAIちびっこが常駐）
3. Webクライアントの 🎬 ボタン、またはアプリの「家族」タブ → デモ から（上から順にやると4つの場面になります）：
   - **けはい: 妹が帰宅**：スマホの画面端から妹が「ただいま」／アプリのリビングでは玄関のドアが開く
   - **見守り: 朝の「元気？」** → おばあちゃんの返事が家族に届く／**調子わるい**・**5時間操作なし**・**電池9%**
   - **けはい: お昼寝**：おばあちゃんがソファでうとうと
   - **雨の日の迎え**：妹ちびっこが歩いて来て窓をノック → 吹き出しから「今行く！」
   - **冷蔵庫メモ**：10秒後に母ちびっこが踊って通知
   - **電気消して**：AIがMCPで消灯 →「おうち」タブの電球が消える／「なぜ？」で根拠表示
   - **土曜の予定**：パパ（非公開）に聞きに行き、数秒後に回答を集計
   - **誕生日**：家族全員のちびっこが集合してお祝い
4. ちびっこを掴んで投げる／画面外へ投げる → 戻ってくる
5. 画面をOFFにして急ぎの連絡 → ロック画面にちびっこ
